## Основной рабочий сервер

Сохранить текущий guarded_mcp.py, существующий Python backend и каталог управляемых копий. Установить только подтверждённый пользователем выпуск обычного AutoCAD: 2018 (R22.0) или 2021 (R24.0), без автоматического выбора. Civil 3D запрещён. Не заменять рабочую регистрацию прямым uvx. Не запускать CAD автоматически.

Перед записью получить drawing_units/active_drawing, проверить фактические единицы и WCS; INSUNITS — метаданные вставки, а не доказательство единиц измерений. Для одинаковых объектов использовать add_geometry_batch (до 200 объектов и 10 000 вершин, точный путь управляемой копии, ожидаемый INSUNITS). При частичной ошибке не повторять автоматически. В остальном использовать модельные фильтры layer/object_type/limit, не выгружать весь DWG. Сырые команды/LISP не включать; допустим локальный проверенный генератор данных для типизированного batch.

## Изолированное сравнение upstream 1.8.0

Следующий TOML — отдельный временный тестовый профиль, НЕ замена действующего сервера. Оставить disabled в рабочем профиле. Установку uv и пакета выполнять после проверки исходников/зависимостей. Только initialize и tools/list, без вызова CAD-инструментов; READ_ONLY — дополнительная защита, не доказательство правильного COM-подключения. ALLOWED_PATHS заменить существующим отдельным каталогом копий. CAD_PROGID должен соответствовать явно выбранному релизу, .22 для 2018, .24 для 2021.

```toml
[mcp_servers.autocad_upstream_probe]
enabled = false
command = "uvx"
args = ["--from", "autocad-mcp-pro[com,pdf]==1.8.0", "autocad-mcp"]
tool_timeout_sec = 300
default_tools_approval_mode = "prompt"

[mcp_servers.autocad_upstream_probe.env]
AUTOCAD_MCP_BACKEND = "com"
CAD_PROGID = "AutoCAD.Application.22"
CAD_LAUNCH = "never"
DISCOVERY_MODE = "search"
TOOL_PROFILE = "lean"
TOOL_PACKS = "core"
ALLOWED_PATHS = "C:/CAD/projects"
READ_ONLY = "true"
MAX_TOOL_COST = "read"
DANGEROUS_COMMANDS_ENABLED = "false"
LISP_POLICY = "read"
```

Прямой COM вызов upstream не допускается до переноса проверки PID/HWND/версии/профиля и защиты каждой операции записи, включая call_tool и cad_batch. Привязка ALLOWED_PATHS сама по себе не защищает от записи в открытый оригинал. Если перенести защиту невозможно, оставить текущий MCP с пакетной обработкой.

## Desktop

Локально выполнить prepare_desktop_plugin.py с фактическим .codex/config.toml, новым каталогом и явно выбранным --release. Не публиковать с локальными путями. Подключить полученный repo-marketplace по официальной инструкции, не перезаписывать персональный marketplace. Диагностический режим по умолчанию; только после подтверждения продукта разрешить COM. Не активировать одновременно плагин и прямой MCP в одном сеансе. Проверить наличие плагина в обычном Chat отдельно; если отсутствует, не использовать Work как будто он расходует обычные сообщения.
