# geo-visual-qa

Проверяй все листы сначала целиком, затем фрагменты с плотными подписями. Сверяй число листов, формат, читаемость текста, шрифты, толщины, видимые слои, обрезку и отсутствие наложений. Проверяй, к чему ведёт стрелка и совпадают ли знак, значение и ID с подтверждённой ведомостью.

Проверь по измеряемому элементу масштаб бумаги с учётом единиц DWG. Сверь масштабы видовых экранов, блокировку и соответствие PDF сохранённому DWG. Обнаруженные дубликаты и совпавшие контуры проверяй по геометрии и роли объектов. Указывай лист, область и наблюдаемое доказательство. При наличии снимков и существенном выпуске используй visual-inspector, если он доступен.

Операции в CAD выполняй только в подтверждённом обычном AutoCAD. Основной режим — 2021, дополнительный при явном выборе — 2018. При неопределённом продукте останови CAD-операцию. Civil 3D, Aecc и открытие DWG по ассоциации исключены.
