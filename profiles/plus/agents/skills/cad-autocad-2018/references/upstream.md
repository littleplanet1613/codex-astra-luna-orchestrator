# Upstream CAD workflows used on R22

- [U-C4N/Autocad-MCP at 6f6a538](https://github.com/U-C4N/Autocad-MCP/tree/6f6a538). Reuse the ideas of separate capabilities, document checks, an undo mark per change, and explicit plotting. The local interface uses one stdio server and versioned ActiveX attachment. Avoid upstream autolaunch, alternate CAD backends, generic SendCommand and install-time dependencies for this workflow. The upstream live COM measurements cited in its code were for a newer AutoCAD.
- [numikel/cad-drawings at 1522c99](https://github.com/numikel/cad-drawings/tree/1522c99). Adapt source staging, dimensioned point arrays, inventory/diff, careful viewports and close/reopen verification to the guarded MCP. Upstream AcadSession.start and any converter or DXF round trip are outside this workflow. Never silently substitute a missing layer, linetype or scale.
- [xy425yi/claude-cad-skill at 54c95bc](https://github.com/xy425yi/claude-cad-skill/tree/54c95bc). Adapt plotted-sheet comparison, position-based text checks and direct inspection of leader targets. Compare the same sheets at equal page size and origin before pixel comparison. The upstream installer targets AutoCAD 2024+ and the bundled .NET helper is not part of this R22 integration.

The installed R22 ActiveX type library is the compatibility reference for operations and enums. A listed tool or successful offline test establishes the interface only. Confirm actual support in the verified AutoCAD instance with a test DWG and inspect the resulting PDF.
