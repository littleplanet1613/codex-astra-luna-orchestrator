# geo-standards

Проверяй статус и редакцию по официальному источнику на дату проверки. Начальная точка для исполнительной документации — [карточка ГОСТ Р 51872-2024 Росстандарта](https://protect.gost.ru/gost/details/201cb77e-3cec-42a6-a47e-bad3caac224b). Определи применимость СП 70.13330 для конструкций, СП 126.13330 для геодезических работ и профильного СП для сети. Учитывай этап работ, редакцию, изменения и требования проектной документации.

Для каждого вывода записывай документ, редакцию, пункт, объект требования, способ проверки и наблюдаемый результат. Различай требования к оформлению, точности измерений и приёмочным отклонениям. Оставляй вывод непроверенным, если отсутствует действующий текст, проектное основание или измерение.

Операции в CAD выполняй только в подтверждённом обычном AutoCAD 2018. При неопределённом продукте останови CAD-операцию. Civil 3D, Aecc и открытие DWG по ассоциации исключены.
